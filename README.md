# 订单消息发送与组合商品处理

## 1. 环境

- 开发工具：JDK 17、Maven 3.9.10。
- 后端：Spring Boot 4.1.2、Spring JDBC。
- 数据库：MySQL 8.4，默认库名 `local_task_message_learning`，地址 `127.0.0.1:3306`。
- 消息队列：RocketMQ 5.x，Proxy 默认地址 `127.0.0.1:8081`。

## 2. 代码说明

1. **下单发消息**：订单和待发消息在同一个事务里保存。保存成功后，后台把消息发到 RocketMQ，下单不用等。
2. **组合商品排序**：下单时把同款、套装逐层展开，先排子商品，再排父商品。清单按商品 ID 和 SKU 去重，随消息保存。添加商品关系时会检查重复和循环关联。
3. **按顺序处理商品**：收到消息后，按清单顺序记录结果，可按订单号查询。同一消费组多次收到同一条消息，只处理一次。
4. **消息补发**：定时任务分批补发漏发或发送失败的消息。默认累计失败 5 次后停止自动补发，填写原因即可手动重试。
5. **任务查询**：按状态分页查任务，查看各状态的数量、失败原因和手动补发记录。
