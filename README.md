# 订单消息发送与组合商品处理

## 1. 环境

- 开发与构建：JDK 17、Maven 3.9.10。
- 后端框架：Spring Boot 4.1.2，使用 Spring JDBC 读写数据库。
- 数据库：MySQL 8.4，默认连接本机 3306 端口的 `local_task_message_learning` 库。
- 消息队列：RocketMQ 5.x，默认连接本机 8081 端口的 Proxy。

## 2. 代码说明

1. **下单发消息**：订单和待发消息在同一个事务里写入 MySQL。事务提交后，后台线程把消息发到 RocketMQ，下单接口不用等发送结果。
2. **组合商品处理**：下单时指定商品，系统会展开同款和套装的多级关系，先排子商品，再排父商品。清单按商品 ID 和 SKU 去重，随订单消息一起保存。数据库用唯一索引防止重复添加同一对父子关系。
3. **消费去重**：消费端按清单顺序逐项记录处理结果。同一消费组重复收到同一条消息，只处理一次。处理结果可以按订单号查询。
4. **失败补发**：定时任务分批补发漏发或发送失败的消息。发送失败后逐步延长重试间隔，默认累计失败 5 次后停止自动重试，可填写原因手动补发。
5. **任务查询**：可以按状态分页查看消息任务，统计各状态的任务数，也可以查看失败原因和人工补发记录。
